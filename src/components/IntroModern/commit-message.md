## Description
Standardizes commit messages, enabling semantic tracking and clear association between changes, tickets, and issues.

Follow Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, etc. One logical change per commit — small and frequent commits. Include the ticket ID in the message (e.g., `feat(orders): APP-321 calculate shipping`).
