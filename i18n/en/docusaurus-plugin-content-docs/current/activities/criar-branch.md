## Description
Create a short branch from `main` or `staging`, ensuring traceability and reducing conflicts.

Name it according to the convention (e.g., `feature/`, `bugfix/`, include squad acronym or task ID).

Update frequently with the main branch to reduce conflict risks.

## Artifacts
- **Input:** Task defined in backlog or ticket
- **Output:** [Activity Branch](/docs/artifacts/branch-atividade.md)
