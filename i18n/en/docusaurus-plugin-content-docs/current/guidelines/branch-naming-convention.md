## Description
Establishes branch naming standards, promoting organization and traceability aligned with business stories and tasks.

Pattern: `type/short-description` (e.g., `feature/login-form`, `bugfix/null-pointer`, `hotfix/limit-check`). Include ticket or squad ID when applicable (e.g., `feature/APP-123-login`). Avoid long-lived branches — integrate with main frequently.
