## Description
Notes summarizing what was delivered in a release: new features, fixes, structural changes, and risks.

## Best Practices
- Generate **automatically** from commits/PRs (Conventional Commits).
- Structure by **Features**, **Fixes**, **Chores**, and **Breaking Changes**.
- Publish and archive as governance evidence.

## Justification
Facilitates communication with stakeholders and change auditing.

## Required?
**No**, but recommended.
