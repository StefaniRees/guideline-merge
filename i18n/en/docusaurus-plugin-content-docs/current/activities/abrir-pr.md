## Description
Open a small and clear Pull Request (PR), filling in the template with context,
changes, impact/risk, and tests performed.
Review may require multiple approvers or specialists.

## Artifacts
**Input:** [Activity Branch](/docs/artifacts/branch-atividade.md), [Standardized Commits](/docs/artifacts/commits-padronizados.md)

**Output:** [Pull Request](/docs/artifacts/pull-request.md)
