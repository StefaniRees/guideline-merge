## Description
Consolidated report of tests performed in the **staging environment**, including automated regressions and exploratory tests.

## Best Practices
- Produce **before** the final merge.
- Include evidence (screenshots, logs, or files).
- Track risks and edge cases.

## Justification
Confirms functional stability before promoting to production.

## Required?
**Yes**
