## Description
Acts as the **initial author of the change**. Responsible for leading the implementation of a priority or more complex task, creating the reference activity branch.
In addition to implementing, tests locally and opens the **initial Pull Request**, which will serve as the basis for subsequent integrations. Takes an active role in **conflict resolution**, as their branch tends to generate the main impact in the merge.

## Responsibilities
- Implement primary or critical tasks
- Create and maintain the reference branch
- Ensure traceability (ticket ↔ commits ↔ PR)
- Resolve conflicts that involve their code as a base
