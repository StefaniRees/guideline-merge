## Description
Branch created from *main* (or staging) to implement a specific change in an isolated and traceable way.

## Best Practices
- Keep branches **short** and **frequently integrated** with the main branch.
- Adopt a clear **naming convention** (e.g., `feature/`, `bugfix/`, `hotfix/`), preferably including the ticket/squad ID.

## Justification
Reduces the risk of late conflicts, improves traceability, and facilitates auditing.

## Required?
**Yes**
