## Description
Report produced by **CI** with results from compilation, tests (unit/integration), linters, coverage, and security checks.

## Best Practices
- Run **for every PR** with **fast feedback** (< 10 min).
- Make the report a **gate**: PR does not advance if it fails.
- Publish **minimum coverage** metrics agreed upon (e.g., 70–80%).

## Justification
Functions as an **automatic quality control** and reduces the risk of regressions.

## Required?
**Yes**
