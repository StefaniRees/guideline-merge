# Code Review — Checklist

> **Purpose:** Establish objective technical review criteria.
>
> **Inputs (Required Artifacts):** PR opened with filled template; CI/CD pipeline approved
>
> **Outputs (Produced Artifacts):** Review comments; Completed review checklist; Technical decision records

## Pre-conditions (Inputs)
- [ ] PR opened with filled template
- [ ] CI/CD pipeline approved

## Execution
- [ ] Code style and conventions evaluated
- [ ] Impact of changes analyzed
- [ ] Test coverage and quality verified
- [ ] Technical risks identified and recorded
- [ ] Security aspects verified
- [ ] Technical decisions recorded

## Quality Gate (Blocking)
- [ ] All Code Review Checklist criteria met
- [ ] All comments resolved before approval
